# NMA — 나만의 뮤직 어워드

아티스트는 운영자가 미리 등록하고 방문자가 검색·선택하는 정적 웹사이트입니다.

등록 방법은 CATALOG-GUIDE.md를 읽어주세요. catalog-editor.html에서 사진과 이름을 등록하고 목록 파일을 저장한 뒤 배포합니다. 방문자의 노래 검색은 기존 iTunes Search API를 유지합니다.

공개 사이트 파일은 dist/에 있습니다. GitHub Pages는 포함된 .github/workflows/pages.yml로 dist를 배포합니다. 관리용 catalog-editor.html은 공개 배포 폴더 밖에 있습니다.

방문자의 라인업과 큐시트는 각자 브라우저에 저장됩니다. 서버에 개인 작성 내용을 저장하지 않으며 브라우저 데이터 삭제나 기기 변경 시 이어지지 않습니다. 기존 위키미디어 기반 선택은 보존하되 새로운 아티스트 검색은 등록 목록에서만 수행합니다.
