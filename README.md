# NMA — 나만의 뮤직 어워드

로그인 없이 각자의 브라우저에서 만드는 팬 메이드 시상식. HTML/CSS/JavaScript 정적 사이트입니다.

## 수정 및 실행

`dist/index.html`, `dist/style.css`, `dist/app.js`를 수정합니다. `python -m http.server 4173 --directory dist`로 로컬 실행할 수 있습니다.

아티스트와 공개 사진은 Wikipedia Action API, 노래 이름은 Apple iTunes Search API(JSONP)에서 검색합니다. API 키는 필요하지 않습니다. 사진은 공식 프로필과 다를 수 있으며 이미지별 원본·저작자·라이선스 링크를 유지해야 합니다. iTunes 앨범 이미지와 음원은 사용하지 않습니다. 서비스 장애·검색 결과 없음·사진 없음에는 직접 입력 및 문자 이미지가 제공됩니다.

작성 내용은 `localStorage`의 `nma-v1`에만 저장됩니다. 서버에 사용자 작성 내용은 저장하지 않습니다. 브라우저 데이터 삭제·기기 변경 시 작성 내용은 유지되지 않습니다. 외부 서비스에 검색어와 일반 접속 정보가 전달됩니다.

## GitHub Pages

이 폴더를 GitHub 저장소에 올리고 Settings → Pages → Source: GitHub Actions를 선택하면 포함된 워크플로가 `dist`를 배포합니다. 수정 후 main 브랜치에 push하면 같은 주소에 반영됩니다. `.openai`는 Sites 배포 식별 정보이며 GitHub Pages에는 업로드되지 않습니다.

## 주요 동작

- 라인업: 시상별 아티스트 검색/선택, 시상 추가, 선택 해제, PNG 내보내기.
- 큐시트 생성: MC, 선택한 수상자·시상, 무대 행을 생성하며 대상은 마지막에 배치합니다. 다시 생성해도 편집한 큐시트를 초기화하지 않습니다.
- 큐시트: 순서 추가/이동/삭제, 아티스트 검색, 시상 텍스트, 노래 검색, 여러 곡 및 PNG 내보내기.
- 하단 열별 버튼은 선택 행에 적용합니다. 선택이 없으면 해당 열이 빈 행 또는 새 행에 적용합니다.

사진을 포함한 PNG는 이미지 서버의 CORS 허용 상태에 따라 문자로 대체될 수 있습니다.
